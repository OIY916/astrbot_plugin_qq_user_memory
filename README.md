# 跨群用户记忆（astrbot_plugin_qq_user_memory）

让机器人换个群也认得人。以 **QQ 号**为主键，把一个人在 A 群、B 群、私聊说过的话
归成同一条记忆线；同时管理这个人的**好感度**和**情绪值**。

自带一个 Web 面板，在 AstrBot 的插件详情页里打开就能看到：人、好感度、情绪曲线。

---

## 功能

### 1. 跨群记忆
- 按 QQ 号聚合，所有群 + 私聊归到一个人
- SQLite FTS5 全文检索，中文逐字切分（不需要 embedding，不花 embedding 的钱）
- 每人在其他群说过什么，回复时补进上下文（同群的由聊天上下文负责，不重复）
- 每人的发言量、活跃群、用过的昵称、最近发言

### 1.5 最近常聊（v1.3.0 新增）
画像只回答「他是个什么人」（长期、静态），回答不了「他这几天在忙什么」（动态）。
插件用 jieba 分词统计最近 7 天的名词语，得出「最近常聊：dsh / astrbot / 记忆 / 插件」，
让模型能接上「你那个 X 弄得怎么样了」，而不是只能演「我认识你」。

完全本地计算，不调用任何 LLM，零成本。

### 2. 每日画像
- 每天固定时刻把活跃用户的发言归纳成 2-3 句「这是个什么人 / 怎么跟他相处」
- 固定用 deepseek-chat，不跟随当前会话模型（省钱且稳定）
- 画像和手动记的事实分开展示，互不覆盖

### 3. 好感度 + 情绪值（双驱模型）
不是存一个「好感 75」的死数字，而是存两个连续量：

| 维度 | 含义 | 变化速度 |
|---|---|---|
| `affection` 好感度 | 长期关系 | 很慢（只有重要的事才动） |
| `warmth` 亲近欲 | 此刻想不想靠近你 | 快（半小时级衰减回基线） |
| `irritation` 烦躁 | 此刻烦不烦 | 最快（十几分钟衰减） |

情绪标签由 warmth × irritation 双线性插值得到，所以是「生气(52%)/不爽(48%)」
这种混合态，而不是非黑即白的「开心/生气多样」。

基线（`base_*`）是长期印象，认识越久越难改：
- 互动 ≤10 轮：可塑性强
- ≤30 轮：减半
- 更多：基本定型

### 4. 群聊 / 私聊分开
同一个人的群聊和私聊是**两份独立状态**（复合主键 `(user_id, scene)`）：

- 群里有别人看着，她客客气气
- 私聊只有你，她耍赖撒娇

群里被骂不会影响私聊，私聊被夸也不会让群里突然变温柔。

### 5. 不拖慢回复
情绪分析是**并行**的：

```
第 N 轮你说完
  ├─ 立刻用第 N-1 轮已分析好的情绪生成回复   ← 主链路，零等待
  └─ 后台异步分析第 N 轮，结果留给下一轮      ← 不阻塞
```

情绪本来就该慢半拍 —— 上一句话带来的情绪，下一句话才体现，反而更真实。

提示词只追加到最后一条 user 消息，**绝不动 system_prompt**，
所以不会破坏主对话的缓存（KV Cache）。

## 指令

```
/记忆 查 <QQ号或昵称>      看这个人的完整档案
/记忆 搜 <关键词>           全文检索所有群里的发言
/记忆 记住 <QQ号> <内容>    手动记一条事实
/记忆 忘记 <QQ号>           删除某人的全部记忆（管理员）
/记忆 统计                  看库里有多少数据
/记忆 最近                  看最近记录情况
/记忆 更新画像 [QQ号]       立刻生成/刷新画像（管理员）
/记忆 画像时间 HH:MM         改每日画像时间（免重启）

/好感 <QQ号或昵称>          查好感度（含亲近/烦躁/当前情绪）
/好感 排行 [N]              好感度排行榜
/好感 设 <QQ号> <0-100>     手动设定好感度
/好感 私聊 <QQ号>           看私聊场景的好感度
```

## 配置要点

| 配置项 | 默认 | 说明 |
|---|---|---|
| `enable` | true | 总开关，关掉既不记录也不注入 |
| `inject_memory` | true | 回复时注入记忆 |
| `inject_on_all` | false | 默认只在 @机器人 时注入，避免读空气也吃 token |
| `max_inject_chars` | 300 | 注入长度上限 |
| `min_messages_before_inject` | 20 | 说话太少的人不注入 |
| `enable_emotion` | true | 情绪系统开关 |
| `enable_mood_llm_analysis` | true | 情绪用 LLM 细判（关掉纯关键词，省钱但没那么准） |
| `mood_llm_max_per_hour` | 60 | 情绪分析每小时最多调几次 LLM |
| `affinity_viewer_qq` | 空 | `/好感` 指令的可见范围，留空=所有人 |
| `enable_daily_profile` | true | 每日画像 |
| `profile_time` | 00:00 | 每日画像时刻 |

## Web 面板

在 AstrBot 的「插件」→「跨群用户记忆」→ 页面入口打开，包含：

- **用户列表**：按发言数 / 最近活跃 / 好感度排序
- **单人档案**：画像、手动记录、活跃群、昵称演变、最近发言
- **情绪状态**（新增）：群聊 / 私聊切换，好感度 + 亲近欲 + 烦躁条形图，
  以及情绪变化曲线（Canvas 绘制，无外部依赖）
- **好感排行**、**群组分布**、**全文检索**

面板接口（10 个）：

```
stats / users / profile / affinity / groups / search
emotion / emotion_history / emotion_all / emotion_adjust
```

## 数据位置

```
data/plugin_data/astrbot_plugin_qq_user_memory/
  ├─ user_memory.db    记忆库（users / messages / facts / user_groups）
  └─ mood_dual.db      情绪库（mood_state_v2 / mood_history_v2）
```

两个库都可以随时备份/迁移。`mood_state_v2` 的主键是 `(user_id, scene)`。

## 安装

1. 把插件目录放到 `data/plugins/astrbot_plugin_qq_user_memory/`
2. 重启 AstrBot
3. 在 WebUI 的插件配置页按需改配置

依赖：Python 标准库 + AstrBot ≥ 4.14.0。

可选依赖 `jieba`：用于「最近常聊」的主题分词。**AstrBot 本体已自带 jieba**，通常无需单独安装。
若环境中确实没有，插件会自动退回 n-gram 统计（质量略低但功能不中断），不会报错。

---

## 已知边界

- 检索用逐字切分，不是语义检索 —— 「钓鱼」搜不到「垂钓」
- 情绪分析默认走当前会话的模型，可用 `enable_mood_llm_analysis` 关掉纯关键词
- 好感度默认从 50 起，只有真的发生互动才会动
- 每日画像固定用 deepseek-chat，需要在 `data/cmd_config.json` 里配好 deepseek 的 key
